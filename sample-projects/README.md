# Thanh Hai 2D Studio — Sample Projects

Thư mục chứa các mẫu dự án hoạt hình chuẩn cho Thanh Hai 2D Studio (Canvas 2D + Three.js):

1. **thanhhai-reaction-time.zip**: Mẫu hoạt hình 2D khoa học vui (What if your reaction time was 10x faster? — hỗ trợ Chibi V9 & Original Stickman).
2. **thanhhai-scared-roommates.zip**: Mẫu hoạt hình White Cartoon 2D (Hai bạn trùm chăn sợ ma trong phòng khách ban đêm — hỗ trợ phong cách White Cartoon 2D).
